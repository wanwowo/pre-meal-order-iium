# Pre-Meal Order IIUM

INFO 3305 – Laravel Group Project  
International Islamic University Malaysia (IIUM)

---

## 📌 Project Description

Pre-Meal Order IIUM is a web-based system built using **Laravel** that allows students to:

- View Mahallah cafes
- Browse available menus
- Order meals before peak hours
- Reduce queue time at campus cafes

---

## 🛠️ Tech Stack

- **Laravel 10**
- **PHP 8**
- **MySQL**
- **Tailwind CSS**
- **Vite**
- **Node.js**
